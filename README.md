# Faceless Wealth Builder

A lightweight web MVP built for a faceless content and course business with automated income streams, educational offers, and analytics.

## Stack

- Next.js 14
- TypeScript
- CSS Modules / global CSS

## Features

- Marketing landing page
- Course catalog
- Pricing and membership tiers
- Dashboard and revenue overview
- Landing, course, pricing, and login pages

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000

## Build for production

```bash
npm run build
npm run start
```
